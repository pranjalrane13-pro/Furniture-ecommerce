# Furniture-ecommerce
Modern furniture shopping platform developed using React, Express.js, Node.js, and MySQL.

## Features

- User Login & Registration
- JWT Authentication
- Product Management
- Shopping Cart
- Order Management
- Responsive Design

## Technologies

- React.js
- Node.js
- Express.js
- MySQL
- JWT
- Bootstrap

## Installation

```bash
npm install
npm start
```
